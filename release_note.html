2026-10-29 — 수업용 도구 2종: 발표자 뽑기 룰렛, 팀 셔플러

발표자 뽑기 룰렛(picker.html)

  • 원형 룰렛이 감속하며 멈춰 발표자를 뽑는다. 뽑힐 사람을 먼저 균등 확률로 정하고 그 칸에 멈추도록 각도를 맞춘다.
  • 뽑힌 사람 빼기(기본 켬), 결석자 일시 제외, 되돌리기, 한 번에 1~5명 뽑기, 뽑힌 순서 기록을 지원한다.
  • 모두 뽑히면 "한 바퀴 더" 또는 "처음부터"를 고른다. 새로고침해도 진행 상태가 복원된다.

팀 셔플러(team-shuffle.html)

  • 명단을 팀 수 또는 팀당 인원으로 나눈다. 조 간 인원 차이는 최대 1명이다.
  • 같은 팀 금지 짝과 조장 후보 분산을 지원하고, 조건을 만족할 수 없으면 원인이 된 짝을 알려준다.
  • 제약이 없으면 Fisher–Yates로 완전 균등 무작위 배치한다.
  • 이름 카드가 한 장씩 조 칸으로 날아가는 연출(속도 조절, 한 번에 보기), 조 이름 수정, 결과 복사를 지원한다.

허브

  • 두 도구의 카드를 허브에 추가했다. 둘 다 js/roster.js 명단 모듈을 쓴다.

2026-10-29 — 새 게임 4종, 모바일 터치 지원, 명단 공통 모듈

새 게임

  • 궤도 점프(orbit-hop.html): 행성 궤도를 도는 위성을 탭 한 번으로 발사해 다음 궤도에 붙이는 원버튼 아케이드. 진행할수록 행성이 작아지고 빨라지며 소행성이 나온다.
  • 낙하 블록 듀얼(block-duel.html): 한 키보드로 둘이 겨루는 블록 쌓기. 줄을 지우면 상대 보드에 방해 줄이 올라가고 3판 2선승이다. 기존 TetrisGame 클래스를 옵션으로 재사용한다.
  • 기억 패드(memory-pad.html): 빛나는 패드 순서를 외워 따라 누르는 기억력 게임. 패드 4/6/9개, 혼자 하기와 2~6인 파티 모드(탈락 서바이벌)가 있다.
  • 둘은 진실(two-truths.html): 발표자의 세 문장 중 거짓 하나를 찾는 수업·모임용 투표 게임. 득표 입력, 공개 연출, 누적 점수판, 결과 복사를 지원한다.
  • 허브(index.html)에 네 게임 카드를 추가했다.

모바일 터치

  • 공 피하기·네온 벽돌깨기: pointer 이벤트로 바꿔 손가락 드래그로 조종한다. 벽돌깨기 캔버스는 4:3 비율로 화면에 맞게 줄어들고, 축소 시 패들 좌표가 어긋나던 문제를 고쳤다.
  • 테트리스: 보드 제스처(탭 회전, 드래그 이동, 스와이프 하드 드롭)와 터치 기기용 하단 버튼을 추가했다.

공통·정리

  • 사다리 게임의 명단 붙여넣기·인원수 선택을 js/roster.js(window.Roster)로 분리해 사다리 게임과 둘은 진실이 함께 쓴다. 사다리 게임 동작은 바뀌지 않았다.
  • 최고점수 저장 키를 gm_<게임명>_best로 통일했다. 테트리스는 최고점수를 새로 저장하고, 공 피하기는 기존 highScore 값을 한 번 옮겨온다.
  • 네온 벽돌깨기에 허브로 돌아가는 링크를 추가했다.

2026-10-29 — 사다리 게임: 공정성·안정성 수정

결과 공정성

  • 사다리 결과가 균등하게 나오도록 생성 방식을 바꿨다. 이전에는 가로줄을 왼쪽 열부터 채우고 행도 부족해서, 10명 기준 한 결과의 확률이 1.1%~21.2%로 치우쳤다.
  • 위쪽 행은 보기 좋게 무작위로 깔고, 아래쪽 n행은 미리 균등하게 뽑은 도착 순서에 맞춰 가로줄을 놓는다. 6만 회 시뮬레이션에서 10명 기준 9.6%~10.3%(기대값 10%)로 확인했다.
  • 가로줄이 하나도 없는 열 쌍이 드물게 생기던 문제를 고쳤다.

보안

  • 결과 카드에 이름·순서를 넣을 때 HTML 이스케이프를 적용했다. 이름에 넣은 스크립트가 실행되던 문제(XSS)를 막는다.

안정성

  • 공이 내려가는 동안 명단·인원수·명단 붙여넣기를 잠근다. 도중에 인원을 바꾸면 오류가 나서 버튼이 계속 꺼져 있던 문제를 고쳤다.
  • 결과를 화면 좌표가 아닌 가로줄 정보로 계산한다. 창 크기를 바꿔도 결과가 틀어지지 않는다.
  • 명단·순서·인원이 바뀌면 이전 결과를 지운다. "순차 공개"는 결과를 다시 계산하지 않고 다시 그리기만 한다.
  • 새로고침해도 같은 사다리와 결과가 복원된다.
  • 명단 적용 후 "순차 공개" 버튼 표시가 실제 상태와 어긋나던 문제를 고쳤다.
